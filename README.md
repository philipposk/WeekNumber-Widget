# Week Number Widget

[![Android](https://github.com/philipposk/WeekNumber-Widget/actions/workflows/android.yml/badge.svg)](https://github.com/philipposk/WeekNumber-Widget/actions/workflows/android.yml)
[![iOS](https://github.com/philipposk/WeekNumber-Widget/actions/workflows/ios.yml/badge.svg)](https://github.com/philipposk/WeekNumber-Widget/actions/workflows/ios.yml)

Week Number Widget is a small, clean phone widget that shows the current week
number — like "Week 22" — on your screen. It's for anyone who thinks in week
numbers (common in Europe and at work) and wants to know which week it is at a
glance, without opening an app. Available for both Android and iPhone.

## What it does
- Shows the current week number on your home screen (and, on iPhone, the lock screen)
- Counts weeks the standard European way by default (weeks start on Monday)
- Offers a US-style mode too (weeks start on Sunday)
- Switches automatically between light and dark to match your phone
- Localizes the "Week" label into 30+ languages
- Lets you customise colours and the label per widget
- Refreshes itself at midnight

## Status
Native apps for Android and iPhone, in separate folders. Both build and are
unit-tested; CI runs on every push.

> Note: Android removed system *lock-screen* widgets in Android 5.0, so on Android
> this is a home-screen widget. iPhone supports both home and lock screen.

### For developers
Two independent native builds — see **[AGENTS.md](AGENTS.md)** for exact commands
and architecture rules, and **[CONTRIBUTING.md](CONTRIBUTING.md)** to make changes.

- `android/` — Kotlin + Gradle. Min SDK 26, target SDK 34.
  `cd android && ./gradlew assembleDebug`
- `ios/` — SwiftUI + WidgetKit, iOS 17+. Project is generated by XcodeGen.
  `cd ios && xcodegen generate && open WeekNumberWidget.xcodeproj`

Standing code-review notes live in **[AUDIT.md](AUDIT.md)**. The marketing website
is a separate project (`Week-Number-Widget--site-`).

### Privacy
No accounts, no network, no analytics, no personal data — everything runs on
device. See `android/PRIVACY_POLICY_TEMPLATE.md`.
